How results are graded

  1. Valid kernel

    The harness runs static checks on the code, replays it bit for bit in a clean process, and tests invariance on targets with exact draws. A kernel that does not preserve the target distribution scores zero.

  2. Efficient on every shape

    The judge tests fresh Gaussians, funnels, bananas, Rosenbrock ridges, mixtures and heavy tails in 6 and 20 dimensions, at a short and a long budget. The score is a soft minimum across shape classes, so the worst class sets it.

  3. Passes on real posteriors

    On Stan models from posteriordb, every checked quantity must lie within 0.1 posterior standard deviations of the reference at 99.5% confidence. A result that fails this check gets no speed score.

  4. Reproduced by a maintainer

    A maintainer reruns the submission on new seeds before marking it verified and admitting it to a ranking.
