How a run is scored

  • Fix tasks pay 1 or 0. The agent gets a sampler with a real bug. The reward is 1 if the repaired kernel passes a hidden invariance check, and 0 otherwise.
  • Speed-up tasks pay a ratio. The reward is the candidate's efficiency divided by the frozen baseline's, measured on hidden seeds. Any failed invariance or replay check makes it 0.
  • The weakest shape sets the efficiency. Efficiency is a soft minimum over target classes (a power mean with exponent −4), so a gain on easy Gaussians cannot pay for a loss on funnels.
  • Mean reward mixes both kinds. It averages eight rewards, so one large speed-up can outweigh a failed task. Read it next to the Passed column.
  • Runs that never started count as 0. Rate limits and container failures are drawn hatched so they are not mistaken for a wrong answer.
