Lanes

A lane is one part of a sampler that an agent may change, with a fixed judge that scores each change. Pick a lane and give its prompt to a coding agent.

Tracks

A track ranks a finished sampler on real Stan posteriors. Each track measures something different, and their results are never pooled.

To enter a track, package the sampler under records/<release>/<track>/<date>_<slug>/, check it with uv run apin records validate, and open a pull request. The rules are in BENCH.md.
