# Archive

This file lists what the old research repository held and apin does not. The old repository is `github.com/sims1253/apin` at commit 9b7d69b71858d00c63016c48c4baaa4ce42ca448 (30 August 2026). Every path below is a path in that commit. Sizes are apparent sizes on disk.

Nothing here is lost while that commit exists. Owner decision: where the raw data lives from now on, and whether the old repository stays as it is, becomes an archived repository, or gets a tag at 9b7d69b before any change to it.

## What was never in the old repository

Run directories (`runs/`), compiled models and the scratch files named above lived only on the machine that ran the campaign. If that machine still has them, the owner decides whether they go next to the old repository (for example as a release asset or in separate storage) or are deleted. apin does not need them to run.
